# Day 3 - Python Data Types

------------------------------------------------------------------------

## What are Data Types?

A **data type** describes the kind of value stored in a variable and
determines how Python can work with that value.

Python has several built-in data types, including text, numeric,
sequence, mapping, set, Boolean, binary and `None` types.

For example:

``` python
name = "Nicola"
age = 32
height = 1.70
learning_python = True
```

These variables contain different data types: `str`, `int`, `float` and
`bool`.

The `type()` function can be used to check the data type of a value or
variable.

## What is Covered in Day 3?

During Day 3, the focus is on understanding Python's built-in data
types, working with numeric values and converting values between
different data types.

The topics covered include:

-   Understanding what a data type is.
-   Recognising Python's main built-in data type categories.
-   Using `type()` to check the data type of a variable.
-   Understanding that Python normally determines data types
    automatically.
-   Understanding the three numeric types: `int`, `float` and `complex`.
-   Working with positive and negative integers.
-   Working with floating-point numbers.
-   Writing floats using scientific notation with `e` or `E`.
-   Recognising complex numbers using `j`.
-   Understanding what casting is.
-   Converting values using `int()`, `float()` and `str()`.
-   Understanding what happens when a float is converted to an integer.
-   Converting numeric strings into numbers.
-   Converting numbers into strings.
