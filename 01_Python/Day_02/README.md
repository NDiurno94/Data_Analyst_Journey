## What are Variables?

A **variable** in Python is a name used to store a value that can be used or changed later in a program.

A variable is created by assigning a value to it using the equals sign (`=`).

For example:

```python
name = "Nicola"
age = 32
height = 1.70
learning_python = True
```

Variables can store different types of data, such as strings, integers, floating-point numbers and Boolean values.

Python also allows variables to change their value and even their data type during the execution of a program.

## What is Covered in Day 2?

During Day 2, the focus is on understanding how variables work in Python and how they can be used to store, modify and display information.

The topics covered include:

- Creating and assigning values to variables.
- Understanding basic data types such as `str`, `int`, `float` and `bool`.
- Changing the value and data type of a variable.
- Checking data types using `type()`.
- Converting between data types using `str()`, `int()` and `float()`.
- Understanding the rules for naming variables.
- Using Python naming conventions such as `snake_case`.
- Assigning multiple values to multiple variables.
- Unpacking collections into variables.
- Displaying variables using `print()`.
- Printing multiple variables together.
- Using the `+` operator for addition and string concatenation.
- Combining different data types using casting.
- Understanding the difference between global and local variables.
- Using the `global` keyword.
