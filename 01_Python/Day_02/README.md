## Day 2 - Python Variables

A **variable** in Python is a name used to store a value that we can use or change later in our program.

We create a variable by giving it a name and assigning a value using the `=` sign.

For example:

```python
name = "Nicola"
age = 30
height = 1.70
```
In this example:

- name is a variable containing the value "Nicola".
- age is a variable containing the value 30.
- height is a variable containing the value 1.70.

Once a value is stored in a variable, we can use the variable instead of writing the value again.

```python
print(name)
print(age)
print(height)
```

Variables make our code easier to read, reuse and modify.
