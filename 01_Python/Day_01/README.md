# Day 1 - Introduction to Python

---

## What is Python?

Python is a popular programming language created by Guido van Rossum and first released in 1991.

Python is designed to have a simple and readable syntax, making it a good language for beginners while also being widely used in professional software development.

Python can be used for many different purposes, including:

- Data analysis and data science.
- Web development.
- Software development.
- Mathematics and scientific computing.
- Automation and scripting.
- Working with databases and files.

---

## Why Python?

Python is one of the most widely used programming languages and can be used across many different fields.

Some of its advantages include:

- Python works on different platforms such as Windows, macOS and Linux.
- Python has a relatively simple and readable syntax.
- Python programs can often be written using fewer lines of code than some other programming languages.
- Python code can be executed directly using the Python interpreter.
- Python supports different programming approaches, including procedural, object-oriented and functional programming.
- Python has a large ecosystem of libraries and tools.

For this learning journey, Python will eventually be used for programming, data analysis and working with data.

---

## What is Covered in Day 1?

Day 1 introduces the basic structure of Python and how a simple Python program works.

The topics covered include:

- Understanding what Python is.
- Understanding what a `.py` file is.
- Running a Python file from the terminal.
- Writing the first Python program.
- Using the `print()` function.
- Understanding Python statements.
- Understanding the order in which statements are executed.
- Understanding indentation and code blocks.
- Using the standard 4-space indentation convention.
- A first introduction to variables.
- Displaying variables with `print()`.
- Working with integers and floating-point numbers.
- Performing basic mathematical operations.
- Combining text and numbers inside `print()`.
- Using the `end` parameter with `print()`.
- Understanding basic Python comments.

## Objectives

By the end of Day 1, I should be able to:

- Understand what Python is and what it can be used for.
- Create and recognise a Python `.py` file.
- Run a Python program from the terminal.
- Use `print()` to display information.
- Understand what a Python statement is.
- Understand that statements normally execute from top to bottom.
- Use indentation correctly.
- Understand why indentation is important in Python.
- Create simple variables and print their values.
- Recognise integers and floating-point numbers.
- Perform simple mathematical operations in Python.
- Display text and calculated values together.
- Use `end` to control how `print()` displays output.

- Apply the concepts learned through practical exercises.

## Files

- `hello.py` - Contains my first Python program and introduces the `print()` function, Python statements and the order in which statements are executed.

- `syntax.py` - Covers the basic Python syntax introduced during Day 1, including indentation, statements, `print()`, a first introduction to variables, numbers and basic mathematical operations.

- `exercises.py` - Contains practical exercises covering the concepts learned during Day 1, followed by a final challenge combining multiple topics.

---

## Practice

The exercises are designed to be completed without looking at the theory files whenever possible.

The goal is to understand the basic Python syntax rather than simply copy examples.

The exercises begin with simple `print()` statements and gradually introduce indentation, variables, numbers and mathematical operations.

The final challenge combines several Day 1 concepts into a small Python program.

---

## Day 1 Outcome

At the end of Day 1, I should understand the basic structure of a Python program and be able to write and execute simple Python code.

I should be comfortable using `print()`, writing statements, using indentation correctly, creating basic variables and performing simple mathematical operations.

These fundamentals will provide the foundation for Day 2, where variables, data types, naming conventions, casting, output and variable scope are explored in more detail.
