# Day 5 - Python Operators

## Topic

Python operators are symbols or keywords used to perform operations on values and variables.

This lesson covers:

- Arithmetic operators
- Assignment operators
- Comparison operators
- Logical operators
- Identity operators
- Membership operators
- Bitwise operators
- Operator precedence

## Important Rules to Remember

1. `/` always returns a floating-point number.
2. `//` performs floor division: it rounds the result down.
3. `%` returns the remainder of a division.
4. `**` means exponentiation, not multiplication.
5. `=` assigns a value; `==` compares two values.
6. Comparison and logical operations return `True` or `False`.
7. Use `is` to test whether two variables refer to the same object, not whether their values are equal.
8. Use `in` to check whether a value exists inside a string or collection.
9. Parentheses make the intended order of operations clearer.

## Practice Advice

- Run the program after every small change.
- Predict the output before executing the code.
- Print both the result and its type when you are unsure.
- Pay close attention to the difference between `=`, `==`, and `is`.
- If an expression looks confusing, add parentheses.
