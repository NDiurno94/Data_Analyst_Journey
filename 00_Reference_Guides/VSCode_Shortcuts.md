# VS Code Shortcuts

A collection of the keyboard shortcuts I use most often while working in Visual Studio Code.

---

| Shortcut | Action |
|----------|--------|
| `Ctrl + S` | Save the current file |
| `Ctrl + P` | Quickly open a file by typing its name |
| `Ctrl + Shift + P` | Open the Command Palette |
| `Ctrl + Shift + V` | Open Markdown Preview |
| `Ctrl + K`, then `V` | Open Markdown Preview in Split View |
| `Ctrl + Shift + C` | Copy selected terminal text |
| `Ctrl + V` | Paste |
| `Ctrl + A` | Select all terminal text |
| `Ctrl + /` | Comment or uncomment selected lines |
| `` Ctrl + ` `` | Open or close the integrated terminal |

---

# Markdown Workflow

When writing documentation:

1. Write in the Markdown editor.
2. Press **Ctrl + K**, then **V**.
3. Edit on the left and preview on the right.

This displays the README exactly as it will appear on GitHub.

---

# Recommended Workflow

When creating a new lesson:

1. Open the project folder.
2. Open the integrated terminal.
3. Create folders and files.
4. Save (`Ctrl + S`).
5. Preview documentation (`Ctrl + K`, then `V`).
6. Commit and push changes to GitHub.
