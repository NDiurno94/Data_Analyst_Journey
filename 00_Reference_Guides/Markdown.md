# Markdown

Markdown is a lightweight markup language used to format text.

It is commonly used for:

- README files
- GitHub repositories
- Documentation
- Notes
- Wikis

Markdown is easy to read, simple to write, and is the standard language used for documentation on GitHub.

---

# Headings

Use the `#` symbol to create headings.

| Markdown | Description |
|----------|-------------|
| `# Heading 1` | Main title |
| `## Heading 2` | Section heading |
| `### Heading 3` | Subsection |
| `#### Heading 4` | Smaller subsection |

Example:

```markdown
# Python
## Variables
### Integers
```

---

# Paragraphs

Leave one blank line between paragraphs.

```markdown
This is the first paragraph.

This is the second paragraph.
```

---

# Text Formatting

| Markdown | Output |
|----------|--------|
| `**Bold**` | **Bold** |
| `*Italic*` | *Italic* |
| `***Bold Italic***` | ***Bold Italic*** |
| `~~Strikethrough~~` | ~~Strikethrough~~ |

---

# Bullet Lists

```markdown
- Apple
- Banana
- Orange
```

Output:

- Apple
- Banana
- Orange

---

# Numbered Lists

```markdown
1. First
2. Second
3. Third
```

Output:

1. First
2. Second
3. Third

---

# Task Lists

Useful for project planning.

```markdown
- [x] Git completed
- [x] Markdown completed
- [ ] SQL
- [ ] Pandas
```

Output:

- [x] Git completed
- [x] Markdown completed
- [ ] SQL
- [ ] Pandas

---

# Links

```markdown
[GitHub](https://github.com)
```

Output:

[GitHub](https://github.com)

# Images


# Inline Code

Use a single backtick (`).

```markdown
`git status`
```

Output:

`git status`

Useful for:

- Commands
- Variables
- File names
- Function names
